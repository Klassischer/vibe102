# Feature PRD: Dark Mode Toggle & Color Scheme Buttons

## Overview

This feature introduces:
- A **Dark Mode Toggle** for the entire app.
- Three **Color Scheme Buttons** that allow users to switch between different predefined color themes for the app.

---

## Goals

- Allow users to switch between light and dark mode.
- Allow users to choose between three distinct color schemes (themes) for the app.
- Ensure the feature is accessible, responsive, and visually consistent with the rest of the app.

---

## Requirements

### 1. Dark Mode Toggle

- A toggle (button or switch) is visible in the app header or settings area.
- When toggled:
  - The app switches between light and dark mode.
  - The mode is applied globally (e.g., by toggling the `dark` class on `<html>`).
  - The toggle should visually indicate the current mode (e.g., sun/moon icon, color change).
- (Optional) Remember the user's choice (e.g., via `localStorage`).

### 2. Color Scheme Buttons

- Three buttons, each representing a different color scheme (e.g., "Blue", "Green", "Red").
- When a button is clicked:
  - The app's color palette changes to the selected scheme.
  - Only one color scheme can be active at a time.
  - The active button is visually highlighted.
- There should be a way to reset to the default color scheme (optional).

### 3. UI/UX

- Use shadcn/ui components for buttons and toggles where possible.
- Controls should be accessible (keyboard, screen reader).
- Controls should be responsive and work on all device sizes.
- The feature should not interfere with core app functionality.

---

## Out of Scope

- Per-page or per-component color schemes (only global).
- Custom user-defined color schemes (only three presets).
- Persisting color scheme state across sessions (unless requested).
